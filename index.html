1. 광원 사냥꾼 (Torch Hunter) A / 눈

목적어두운 방 안에서 시야 자체가 자원이 되는 코어. Alien Isolation 공포를 순수 관조로 재해석.
원리검은 화면 위 커서 = 손전등 원. 원 안에 순간 잡히는 그림자·움직임·형태로 상황을 재구성. 원 밖은 항상 어둠.
재미어두움을 훑는 원의 감각적 몰입 · 순간 각인의 관조 · 원 밖의 상상 · 놓친 순간의 아쉬움.
언어 노출0~5자 · LLM 백엔드 판정 여지 있음

2. 모래시계 뒤집기 (Hourglass Turn) B / 손

목적중력·모래 흐름이 코어. Powder Toy 자매지만 "뒤집기 타이밍이 곧 결과" 코어는 부재.
원리유리 모래시계 · 모래 흐름 · 화면 회전으로 중력 방향 전환 · 여러 번 뒤집기로 층층이 쌓임 · 완성 형태에 맞춤.
재미중력 전환의 손맛 · 알갱이 쌓임의 시각 만족 · 즉시성 · 정지 순간의 미학.
언어 노출0~3자 · LLM X

3. 눈으로 듣기 (Visual Rhythm) A/C / 귀

목적청각 자산 없이 시각 파형·색·펄스만으로 리듬 게임 성립하는지 실험. Tetris Effect의 완전 무음 버전 · 시장 완전 부재.
원리화면 전체 색·펄스·파형 흐름 · 소리 전혀 없음 · 시각 리듬 패턴을 눈으로 읽어 정박에 커서를 두드림.
재미소리 없이 시각으로 리듬을 느끼는 새 감각 · 화면 펄스가 자기 심박처럼 · 완전 침묵 속 몰입.
언어 노출0자 · LLM X

4. 도미노 (Domino Chain) C / 결

목적연쇄 반응 시각화가 코어. Rube Goldberg 계보 미니멀 재해석 · 순수 시각 연쇄 완결.
원리캔버스 위 물리 오브젝트 배치 · 첫 조각 클릭 → 연쇄 발동 → 목표 지점 도달 → 성공 · 실패는 시각적으로 그대로 보임.
재미연쇄가 흐르는 관조 · 어긋남의 시각적 유쾌함 · 폭포 같은 연쇄 카타르시스 · 세팅 변주의 반복 만족.
언어 노출0~5자 · LLM 백엔드 판정 여지 있음

5. 한 획 (One Stroke) D / 결단

목적짧은 판단 → 즉시 시각 결과. 한붓그리기(오일러 정리) 원리 인디 재해석 · Line Rider 궤적 계보와 코어 다름.
원리화면 위 흩어진 점 · 마우스 눌러 한 획으로 모든 점 잇기 · 펜 떼면 판정 종료 · 점 배치가 매판 달라 매번 새 궤적.
재미펜 떼지 못하는 손 긴장 · 자동으로 남는 궤적 · 순간 판단 · 완성 시 궤적이 하나의 형태되는 발견의 쾌감.
언어 노출0~3자 · LLM X
